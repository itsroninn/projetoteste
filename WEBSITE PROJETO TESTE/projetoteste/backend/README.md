# Backend

O MVP nao possui backend proprio. A captura de leads deve usar formulario estatico, preferencialmente Netlify Forms.

Este dominio so deve ser ativado se houver necessidade real de:
- rotas customizadas;
- banco de dados;
- integracoes externas;
- automacoes server-side;
- processamento seguro de dados.

Antes de implementar qualquer backend, atualize `docs/api-contracts.md`.
